# FCPD - Programming Fundamentals

## Description

This repository contains the work developed for the **Programming Fundamentals** course.

It includes class activities, practical workshops, programming exercises, documentation, and projects developed throughout the semester.

The main programming language used in this repository is **C**.

## Repository Structure

```text
.
├── classes/
├── docs/
├── projects/
└── README.md
```

## Purpose

The purpose of this repository is to keep an organized record of the work developed during the course while practicing programming fundamentals and improving problem-solving skills.

## Compilation and Execution

C programs can be compiled using a C compiler such as `gcc`.

```bash
gcc filename.c -o program
```

Then, run the compiled program with:

```bash
./program
```
